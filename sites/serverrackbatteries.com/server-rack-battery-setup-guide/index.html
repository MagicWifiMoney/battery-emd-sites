How to Set Up a Server Rack Battery Bank

Setting up a server rack bank is five jobs in a fixed order: match the modules, set each one's address, run the communication cables, wire the power cables to a busbar, then power up and check. Most first-day problems (inverter shows no battery, a module throws an error, one pack does all the work) come from doing these out of order. The steps below are the general pattern; your module's manual has the exact switch positions and cable pin-outs, and it wins wherever it differs. Step 1: match the modules before they meet

Use the same brand and model for every module in the bank, and bring them to the same state of charge before connecting them in parallel. The simple way is to charge each module to full on its own, or follow the manual's matching procedure if it gives one. Two modules at different voltages, connected cold, push a large current from one to the other. A rested reading on each module, checked against the 48V LiFePO4 voltage chart, tells you whether they are close.

Step 2: addresses, one master and every pack unique

Rack modules share a communication bus, so each one needs its own address, usually set with DIP switches on the front panel. The manual has a table mapping switch positions to addresses and says which address makes a module the master (the one that talks to the inverter). Set the switches with the modules powered off. Two modules on the same address is the most common cause of a module that won't show up or a bank that throws communication errors.

Step 3: comms cables, pack to pack, then master to inverter

  • Between modules: link cables from each module's link port to the next, as the manual shows.
  • To the inverter: one cable from the master module's CAN or RS485 port to the inverter's battery communication port. Pin-outs differ between brands, so use the maker's cable or build one to its pin-out.
  • In the inverter: select the battery brand or protocol in the inverter's battery settings.

Whether your inverter speaks your module's protocol is the first thing to check, and our inverter compatibility page covers it. Without communication, every module still runs on voltage-based charge settings; the values are on our sister site's 48V charging guide.

Step 4: power cables to a busbar, equal lengths

Run each module to a common positive and negative busbar with cables of the same gauge and the same length, rather than daisy-chaining module to module. Unequal cables make the closest module carry more of the load and age faster. Take the bank's main cables to the inverter from opposite ends of the busbars so current spreads evenly.

Most rack modules have a breaker or switch on the front; you still want a fused disconnect or DC breaker between the bank and the inverter, sized to the inverter manual's cable and current figures. Tighten terminals to the torque the manual gives; a loose lug is a hot lug.

Step 5: the first power-up checklist

  • Switches off on every module; inverter off.
  • Addresses set and double-checked, master identified.
  • Comms cables in the right ports (link ports between modules, master to inverter).
  • Busbar polarity checked with a meter before anything is switched on.
  • Turn the modules on in the order the manual gives (often the master last or first; it matters on some brands).
  • Start the inverter and confirm it shows the battery's state of charge and the right module count.
  • Run a modest load, then a charge, and watch that every module reports similar current.

Frequently asked questions

Do server rack batteries need DIP switches set?

Yes, in a bank of more than one module on most brands. Each module needs a unique address on the communication bus, and the manual says which address makes a module the master. Set them with the power off; duplicate addresses cause missing modules and comms errors.

Do I need a communication cable between server rack batteries?

For a bank that reports one state of charge to the inverter, yes: link cables between modules and one cable from the master to the inverter. Without them the modules still work in parallel on voltage-based charge settings, but the inverter can't read their state of charge or current limits.

Can I add a new server rack battery to an old bank?

Usually, if it is the same brand and model and stays within the maker's parallel limit. Bring the new module to the same state of charge as the bank first, give it its own address, and check whether the maker says firmware versions need to match.
