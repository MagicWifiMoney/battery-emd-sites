The 48V 100Ah (5.12kWh) battery is the standard brick of home solar storage: one module runs a meaningful slice of a house, and modules parallel upward from there. Because every model stores the same 5,120Wh, this is the purest price fight in the category — the table below is the whole story, sorted by $/Wh.

Watch the fine print when comparing: some 100Ah models are rack-mount with inverter communications, others are simple floor batteries for golf carts and off-grid cabins. Same energy, different jobs. Because every model here stores the same energy, the $/Wh gap between the top and bottom of this table is pure price — how that unit is worked out, with live examples, is on the price per watt-hour page.
